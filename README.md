# Terror-en-la-Casa-Historica
El jugador controla a un ladrón que entra de noche a un museo con la intención de robar una joya que se encuentra en el quinto piso. La llegada hasta la joya es relativamente fácil, ya que el museo parece estar vacío y no presenta grandes obstáculos
